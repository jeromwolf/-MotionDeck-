# MotionDeck

YouTube content creators presentation editor with animated slides.

## Features

- **Project Management**: Create, save, and load multiple projects
- **Slide Editor**: Add text, images, icons, code blocks, and shapes
- **Drag & Resize**: Move and resize all elements freely
- **Slide Management**: Reorder, duplicate, and delete slides
- **Layer Control**: Change element z-order (bring to front/back)
- **Undo/Redo**: Ctrl+Z / Ctrl+Shift+Z support
- **Font Styling**: Font family, bold, italic, underline, text alignment
- **Gradient Backgrounds**: 12 preset gradient options
- **Dual Monitor Presenter Mode**: Separate audience and presenter windows
- **Auto Image Compression**: Optimizes large images automatically
- **Export/Import**: Save and share projects as JSON

## Tech Stack

- [Next.js 14](https://nextjs.org) (App Router)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
- [Framer Motion](https://www.framer.com/motion)
- [Lucide Icons](https://lucide.dev)
- IndexedDB for local storage

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view in browser.
